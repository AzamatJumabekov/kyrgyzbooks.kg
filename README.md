# Kyrgyz Publishing — Website

This repository contains a minimal static-site scaffold for the "Animals of Kyrgyzstan" and "Musical Instruments of the Kyrgyz People" publisher site.

Structure:

- `/en/`, `/ky/`, `/ru/` — locale folders (EN built; KY/RU placeholders)
- `/css/`, `/js/`, `/assets/` — static assets
- `/docs/` — TOR and project documentation

To view the site, open `/en/index.html` in a browser (no build step required).
